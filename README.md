# MSF · Nácar y Calderas

Proyecto educativo de Luis MP para explorar Máquinas y Sistemas de Fluidos y compartir su desarrollo con el profesorado.

La aplicación reúne una colección de guardianes, un mapa de regiones, misiones, un altar con temporizador y dos laboratorios interactivos: el Oráculo del Salto y la Forja de Velocidades.

## Abrir la aplicación

Web: https://rexray05.github.io/msf-nacar-y-calderas/

El enlace estará disponible cuando finalice el despliegue de GitHub Pages. Para usar una copia local, conservar `index.html` y la carpeta `assets` juntos.
